Case Study

Onuman

Building the future of architectural estimation with Django and NUXT.

Django NUXT PostgreSQL Electron VPS Nginx
Problem

The Challenge

Architectural firms often rely on disconnected spreadsheets, manual calculations, and repetitive workflows to prepare project estimates. This process consumed valuable time, introduced costly human errors, and made it difficult to scale bidding operations efficiently.

As firms grew, inconsistent pricing models and delayed proposals began impacting competitiveness and internal productivity.

Approach

The Strategy

We developed Onuman, a centralized cloud-based estimation platform tailored for the architecture and construction industry.

The goal was to replace fragmented tools with a single intelligent system that could automate calculations, standardize pricing logic, and simplify proposal generation.

Special attention was given to user experience so architects and project managers could operate advanced tools without technical complexity.

Engineering

What Was Hard

The core challenge was building a calculation engine capable of processing hundreds of linked variables in real time.

Material costs, labor rates, dimensions, regional pricing, dependencies, and custom project logic all needed instant recalculation when values changed.

To solve this, we engineered:

  • A custom Django rules engine for dynamic estimation logic
  • Optimized caching layers for faster recalculations
  • PostgreSQL query tuning for large pricing datasets
  • Responsive Nuxt components for real-time updates
  • Secure multi-role access architecture for internal teams
  • License key based System

Delivery

What We Built

Onuman launched with a complete enterprise-ready feature set:

  • Smart project estimation dashboard
  • Role-Based Access Control (RBAC)
  • Dynamic PDF proposal generation
  • Reusable pricing templates
  • Real-time cost recalculation
  • Client/project management modules
  • Automated scheduled database backups
Experience

Product & UX

The platform used a modern decoupled architecture with Django REST Framework powering APIs and Nuxt 3 delivering a fast interactive frontend. The interface was designed around calm layouts, structured forms, and low-friction workflows to reduce cognitive load for busy professionals handling complex estimates.
